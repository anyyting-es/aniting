# Aniting

Aniting es una aplicación para Android que te permite ver anime y leer manga desde un solo lugar.

Funciona utilizando el servidor de [Seanime](https://github.com/5rahim/seanime) como backend, permitiendo reproducir contenido mediante streaming online o torrents, y leer manga a través de extensiones.

---

## Características

- **Anime**: Reproducción mediante proveedores online y streaming por torrents con soporte para subtítulos.
- **Manga**: Lector integrado con modo de lectura vertical y horizontal.
- **Sincronización con AniList**: Seguimiento automático de episodios vistos y capítulos leídos.
- **Extensiones**: Soporte para instalar proveedores de anime, manga y torrents de la comunidad.

---

## Instalación en Android

1. Entra a la sección de [**Releases**](https://github.com/anyyting-es/aniting/releases).
2. Descarga la versión más reciente del archivo `app-release.apk`.
3. Abre el archivo en tu dispositivo Android e instálalo.
   *(Si es la primera vez que instalas una app fuera de Google Play, autoriza la opción "Instalar aplicaciones desconocidas")*.
4. Abre Aniting y sigue el asistente inicial.
